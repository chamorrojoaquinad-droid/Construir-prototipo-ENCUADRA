Quiero mejorar y ampliar el prototipo móvil existente de mi aplicación **ENCUADRA**, manteniendo el diseño visual actual que ya está creado.

NO rediseñes completamente la pantalla existente. Conserva el estilo actual: fondo oscuro, detalles en naranja, tarjetas redondeadas, tipografía moderna, iconos sencillos y apariencia de aplicación móvil profesional.

El objetivo es agregar una **INDUCCIÓN INTERACTIVA antes de comenzar los juegos**, porque el usuario puede ser un emprendedor que no tiene conocimientos previos de fotografía o producción audiovisual.

La inducción NO debe parecer una clase larga ni una presentación llena de texto. Debe sentirse como parte del juego: visual, dinámica, sencilla, progresiva y entretenida.

# 23. REGLAS IMPORTANTES DE DISEÑO

NO saturar las pantallas.

NO colocar grandes bloques de texto.

NO colocar demasiados botones.

Cada pantalla debe tener:

* Un objetivo principal.
* Un título corto.
* Una imagen o elemento visual protagonista.
* Una explicación breve.
* Un botón principal.

Utilizar fotografías grandes para explicar los conceptos audiovisuales.

Las explicaciones deben aparecer progresivamente.

Utilizar tarjetas, comparaciones, barras de progreso, XP, insignias y microinteracciones.

La aplicación debe sentirse como una combinación entre:

**juego + aprendizaje + fotografía + emprendimiento.**

Debe ser intuitiva incluso para una persona que nunca haya estudiado fotografía.

Mantener consistencia visual entre todas las pantallas.

Utilizar el naranja para acciones principales y recompensas.

Utilizar colores más apagados para niveles bloqueados.

Crear estados:

* Normal
* Seleccionado
* Correcto
* Incorrecto
* Bloqueado
* Desbloqueado
* Completado

Crear prototipo interactivo conectando las pantallas en este orden:

INICIO
→ BIENVENIDA
→ ¿CÓMO FUNCIONA?
→ TU PRIMER RETO
→ MINI ESCUELA
→ LECCIÓN 1
→ LECCIÓN 2
→ LECCIÓN 3
→ PRÁCTICA
→ FEEDBACK
→ RETO PRINCIPAL
→ RESULTADO
→ SIGUIENTE NIVEL
→ MENÚ

Las interacciones deben ser claras y permitir que el usuario avance y vuelva al menú.

El resultado final debe parecer un **MVP de una aplicación real**, no una presentación de diapositivas.

Priorizar una experiencia dinámica, visual, educativa y gamificada.
