## 1. CONCEPTO GENERAL

ENCUADRA es una aplicación educativa dirigida principalmente a emprendedores que quieren aprender a crear mejores fotografías y videos para promocionar sus productos utilizando su celular.

La aplicación enseña producción audiovisual mediante pequeños retos y juegos.

El usuario aprende:

* Tipos de planos
* Ángulos de cámara
* Iluminación
* Composición
* Fotografía de productos
* Creación de contenido para redes sociales

El objetivo es que un emprendedor pueda aprender conceptos audiovisuales de manera sencilla, visual, entretenida y práctica.

El prototipo debe sentirse como una aplicación móvil moderna, profesional, juvenil y relacionada con fotografía y producción audiovisual.

Formato principal: **mobile app vertical 390 x 844 px aproximadamente**.

Estilo visual:

* Fondo oscuro casi negro
* Azul oscuro/gris oscuro para tarjetas
* Naranja como color principal de acción
* Blanco para textos principales
* Gris claro para textos secundarios
* Algunos degradados sutiles
* Bordes redondeados
* Sombras suaves
* Iconografía sencilla relacionada con fotografía
* Diseño limpio y moderno
* Jerarquía visual clara
* Apariencia profesional pero accesible

Mantener el estilo visual de la pantalla inicial existente: fondo oscuro, título grande, botones redondeados y color naranja como elemento de acción.

# 24. EXPERIENCIA DEL USUARIO

El prototipo debe sentirse como un juego educativo, no como una aplicación escolar tradicional.

Usar:

* Animaciones suaves
* Transiciones entre pantallas
* Botones con estados hover/pressed
* Feedback visual al responder
* Microanimaciones para ganar XP
* Barras de progreso
* Insignias
* Celebraciones al completar niveles

Cuando una respuesta sea correcta:

Mostrar una animación breve de celebración y:

**+100 XP**

Cuando sea incorrecta:

Mostrar feedback educativo sin castigar demasiado al usuario.

La aplicación debe enseñar al usuario por qué una respuesta es correcta.
