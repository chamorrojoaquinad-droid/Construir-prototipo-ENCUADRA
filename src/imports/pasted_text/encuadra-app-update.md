NO saturar las pantallas.

NO utilizar grandes bloques de texto.

NO utilizar demasiados botones.

Un objetivo principal.
Un título corto.
Una imagen o elemento visual protagonista.
Una explicación breve.
Un botón principal.

Las fotografías deben tener protagonismo visual, especialmente durante las mini lecciones.

Utilizar:

29. OBJETIVO FINAL

El resultado debe parecer un MVP real de una aplicación móvil, no una presentación de diapositivas.

La experiencia debe transmitir:

“Estoy jugando, pero mientras juego estoy aprendiendo fotografía.”

Las fotografías proporcionadas deben funcionar como ejemplos reales de fotografía profesional, mientras que la interfaz de ENCUADRA debe funcionar como el sistema que explica, guía y convierte esas referencias en desafíos interactivos.

Priorizar:

VISUAL > TEXTO

INTERACCIÓN > LECTURA

PRÁCTICA > TEORÍA

EXPERIENCIA > PRESENTACIÓN

La aplicación debe resultar intuitiva incluso para una persona que nunca haya estudiado fotografía, composición o producción audiovisual.
